# English Study Book

App web para aprender ingles en nivel intermedio-avanzado, orientada a progreso guiado, practica activa y feedback pedagogico.

## Fase 1

La primera fase incluye una experiencia web estatica con:

- Dashboard de progreso.
- Diagnostico inicial.
- Ruta de estudio B1+/B2.
- Practica por habilidades.
- Centro de repaso.

Para probarla con un servidor local:

```powershell
node scripts/serve.js
```

Luego abre `http://localhost:4173`.
